# Workflow

The UI remains simple even though the workflow is controlled.

## User actions
Create → Upload → Check → Calculate → Review → Approve → Publish

## Examination wizard
Programme → Semester → Examination → Courses → Students → Review Rules → Activate

## Marks & Results
Import Marks · Enter Marks · Validate · Calculate Result · Review Trial Result · Scrutiny · Grace · Revaluation · Finalize

## Smart errors
Show a simple summary such as “7 issues need attention”, then categorize missing marks, invalid marks, eligibility issues, and configuration issues.

## Approval
Data Entry cannot approve. Scrutinizer reviews. CoE/authorized academic authority approves, locks, and publishes.

## Locking
After lock, raw marks and calculation inputs cannot be changed. Subsequent revaluation/correction creates a new result version.

## Progressive disclosure
Normal screen: “Grade B+ · Total 72 · Pass”
Optional “Why this grade?” reveals calculation detail.
