# Initial Decisions

## ADR-001
Use Staging and Production from the beginning.

## ADR-002
Use separate databases for Staging and Production.

## ADR-003
Use free tiers wherever feasible until a paying client requires paid infrastructure.

## ADR-004
Start as a modular monolith.

## ADR-005
Store academic policy values in regulation/version configuration.

## ADR-006
Use immutable official result versions.
